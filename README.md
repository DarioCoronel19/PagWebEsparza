# TechNova — GPDS P1 A1

Sitio web colaborativo creado para la actividad de GitHub.

## Estructura
- `index.html` — página principal
- `tecnologia.html` — sección 01
- `ia.html` — sección 02
- `videojuegos.html` — sección 03
- `futuro.html` — sección 04
- `css/styles.css` — estilos compartidos

## Propuesta de ramas
- `main` — versión integrada
- `seccion-tecnologia`
- `seccion-ia`
- `seccion-videojuegos`
- `seccion-futuro`

## Flujo recomendado
1. Cada integrante crea su rama desde `main`.
2. Realiza sus cambios.
3. Hace `git add .` y `git commit`.
4. Hace `git push -u origin nombre-de-rama`.
5. Abre un Pull Request hacia `main`.
6. El responsable del repositorio revisa y hace Merge.
7. Todos actualizan su copia local con `git pull origin main`.

## GitHub Pages
En el repositorio: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
